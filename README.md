# nvim

Мои настройки для nvim

====================================
### Объяснения
====================================

#### Функции-помощники
Это две маленькие обёртки, чтобы не писать одно и то же десятки раз.

##### `map`: обёртка над `vim.keymap.set`

```lua
local function map(mode, lhs, rhs, opts)
  opts = vim.tbl_extend("force", { silent = true }, opts or {})
  vim.keymap.set(mode, lhs, rhs, opts)
end
```

- `mode`: режим (`"n"`, `"i"`, `"v"`) или список режимов (`{ "n", "x", "o" }`).
- `lhs`: что нажимаем.
- `rhs`: что выполняется: строка команды или Lua-функция.
- `opts`: необязательные опции маппинга.

Единственное, что она добавляет, это `silent = true` по умолчанию. Это аналог `<silent>` в Vimscript: Vim не печатает в командной строке сам выполняемый маппинг (`:w<CR>` и т.п.).

Строка `vim.tbl_extend("force", { silent = true }, opts or {})` склеивает две таблицы. Если `opts` не передали, берётся пустая таблица `{}`. Если передали, например `{ silent = false }`, то он перекрывает значение по умолчанию (`"force"` значит, что при конфликте выигрывает правая таблица). Поэтому для `/` и `?` я писал `{ silent = false }`, а для Tab-маппингов `{ expr = true }`, и `silent = true` у них остаётся.

Заметь, что `noremap` не нужен: `vim.keymap.set` по умолчанию делает нерекурсивный маппинг, то есть `nnoremap`.

Пример:
```lua
map("n", "<C-s>", "<Cmd>w<CR>")
-- то же самое, что в .vimrc:
-- nnoremap <silent> <C-s> :w<CR>
```

##### `lmap`: маппинг с `<leader>` и русским дублем

```lua
local function lmap(mode, key, ru, rhs, opts)
  map(mode, "<leader>" .. key, rhs, opts)
  if ru then
    map(mode, "б" .. ru, rhs, opts)
  end
end
```

Она регистрирует один и тот же `rhs` дважды:

1. `<leader>` + `key` (латиница): `<leader>a`.
2. `б` + `ru` (русская раскладка): `бф`.

`б` стоит там, где на английской раскладке запятая, то есть твой `<leader>`. Если на русской раскладке нажать `б`, а затем `ф` (клавиша `a`), получится то, что у тебя в `.vimrc` записано как `nnoremap бф ggVG`.

Если `ru` равен `nil`, русский дубль не создаётся. Так можно писать маппинги без русской версии.

Пример:
```lua
lmap("n", "a", "ф", "ggVG")
-- эквивалент двух строк из .vimrc:
-- nnoremap <leader>a ggVG
-- nnoremap бф ggVG
```

Обе функции объявлены как `local`, то есть видны только внутри `keymaps.lua` и не засоряют глобальное пространство имён.
